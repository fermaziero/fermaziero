## 📌 How I Work

I like building with a practical balance of:

- **Speed** (ship and validate)
- **Structure** (avoid chaos)
- **Scalability** (don’t paint yourself into a corner)
- **Design sense** (product experience matters)
- **Business clarity** (tech must create value)

4. API + frontend implementation
5. QA / refinement
6. Go live + iteration
